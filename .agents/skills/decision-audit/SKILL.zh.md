# decision-audit：漂移巡检

[English](/.agents/skills/decision-audit/SKILL.md) | 中文

`decision-check` 顺着改动查决策；audit 反过来**从决策查实现**。开始前读[记录格式契约](/.agents/se/contracts/note-format.zh.md)与[评审清单](/.agents/se/contracts/review-checklist.zh.md)。

**只读。不动记录、不动代码、不动注释。**

读取记录时遵循[工作流契约](/.agents/se/contracts/workflow.zh.md)：请求文件夹里只有 `proposal` 配对是记录，`discuss-*` / `reply-*` 是非约束性证据；最终批准在人与提案作者的直接对话中。评审贡献与回复格式见[记录格式契约](/.agents/se/contracts/note-format.zh.md)，只读技能不改证据或记录。保留分歧，不把作者回复或门禁通过当作审阅者确认。

## 门禁已经管了的，这里不查

| 已由门禁保证 | 归属 |
|---|---|
| 记录格式、状态与目录一致 | 决策门禁 |
| 链接有效性 | 链接门禁 |
| 被引用文件改动时的陈旧提示 | 链接门禁的 L4 警告 |

**不要重复门禁的活。** audit 的价值在门禁做不到的地方。

## 检查单

### 1. 死决策

一条 `implemented/` 记录的代码锚点和实现全部消失，约束也不再被执行。判断它该归档还是该删除，交给 `decision-revise`。

### 2. 无主实现

安全、隐私、不变量、恒定条件相关的代码，找不到任何决策认领。

**这是本技能独有的一项**——它是一次全仓反扫，不是「本次改动的属性」。发现后：要么补追溯决策，要么确认它确实平凡并记录下来。

### 3. 归档后仍生效

已归档记录的约束仍在代码中运行。这说明归档判断错了——要么恢复为 `implemented/`，要么把实现改掉。

### 4. 绕过率

统计提交信息里 `Decision process: bypassed` 的出现频次与原因分布。旧提交用的是中文标记 `决策流程: 绕过`，统计时一并计入，否则历史绕过节会漏计。

- 绕过率低 → 流程不碍事；
- **绕过率高不是纪律问题，是判据问题**——说明 `AGENTS.md` 里的三类判定切得不对，该改判据而不是加纪律。

```bash
git log --format='%h %s%n%b' | grep -cE 'Decision process: bypassed|决策流程: 绕过'
```

### 5. 债务相变

债务不是静态分数，是**当前实现偏离「按现行决策重新推导出的合理实现」的距离**。过早抽象本身有成本，所以只在成本涨过阈值时才处理。

只看会改变角色的信号，不做周期打分：

| 信号 | 含义 | 动作 |
|---|---|---|
| **复触** | 桥接代码开始被端点决策之外的改动反复触碰 | 考虑升格为决策 |
| **三现** | 同一种折衷出现三处或更多 | 考虑提取成约束 |
| **枢纽密度** | 一个位置承载多条决策 | 考虑合并决策 |
| **重派存活率** | 按当前决策重推后，现有结构能留下多少 | 留得很少 → 重构候选 |

四条里**只有「三现」可以机械化**（grep 重复模式）。其余三条需要判断。

### 6. 记录合规

缺动因、缺作用域、约束无法判定——用[评审清单](/.agents/se/contracts/review-checklist.zh.md)的 `J2` 过一遍。格式问题交给门禁，不在这里重复。

### 7. 悬空提案

`proposed/` 里长期没人推动、且方向已经过时的提案，交给 `decision-revise` 否决（`proposed → rejected`）或继续推进。**提案永不归档。**

## 产出

分两级：

```markdown
audit：<范围>

阻塞观察
  <失效的约束 / 归档后仍生效 / 记录与实现矛盾>
  → 会破坏整个追踪基础，优先处理

工作项
  <无主实现 / 死决策 / 债务相变 / 记录缺陷>
  → 记录侧交 decision-revise，实现侧等用户授权
```

无发现时输出一行 `audit：无漂移`。

## 边界

- 只读代码、记录、文档和 git 历史。
- **判断题必须给依据和置信度；不确定时列为观察，不强行下结论。**
- 发现留在报告里，不直接写进记录。只有升格为约束或导致决策改变时，才走 `decision-revise`。
- 不做周期性分数统计。
