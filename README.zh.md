# dsh-profiler

[English](/README.md) | 中文

dsh-profiler 是一个 Agent 执行过程的热点分析工具：它分析一次执行在哪些步骤、调用与上下文上消耗了时间与 Token，并据此提供可核对的成本事实与潜在异常线索。

具体目标引自[项目宪章](/docs/agent-profiler.zh.md)：通过执行成本分析，为 Agent 的效率优化提供事实依据。Profiler 的职责限定为成本测量与归因，以及基于客观事实识别潜在异常；它不判断某些过程是否必要，也不直接进行效率评价。

项目目前处于早期探索阶段：目标与职责边界已经明确，测量口径、能力范围与交付形态仍在形成中。
