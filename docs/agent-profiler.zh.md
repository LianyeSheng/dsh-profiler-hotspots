# Agent Profiler：目标与职责

[English](/docs/agent-profiler.md) | 中文

本文说明 Agent Profiler 的目标与职责，是本仓库最重要的开发指导。

## 目标

Agent Profiler 通过执行成本分析，为 Agent 的效率优化提供事实依据。

## 成本与效率

在完成相同任务并满足相同质量标准的前提下，成本由时间成本和经济成本构成：

`C = aT + bM`

其中，`a`、`b` 是使用者指定的权重及单位换算系数；经济成本目前主要指 Token 计费。

效率定义为综合成本的倒数：

`E = 1 / C`

因此，降低综合成本即提高效率。主要优化途径包括缩短执行关键路径，以及减少不必要的输入与输出。

## 判断的边界

如何安全地缩短执行路径、哪些输入与输出可以减少，通常需要结合任务目标、执行上下文及复杂的行为分析进行推理。仅依靠成本事实不足以可靠地完成这些判断。

## 职责

Agent Profiler 的职责限定为：

1. **成本测量与归因**：提供可验证、可追溯、测量口径明确的成本消耗事实。
2. **潜在异常识别**：基于客观事实识别潜在异常，提供相关证据与可供调查的优化线索；Profiler 不判断某些过程是否必要，也不直接进行效率评价。

任务质量的评价、效率分析及优化决策，由人类或 Agent 在 Profiler 提供的事实基础上进一步完成。
